Troubleshooting Common Problems

These are the operational issues users run into most often with local encrypted vault workflows.

Vault File Will Not Open

  • Verify the master password carefully.
  • Try an older known-good backup file.
  • Confirm the file was fully downloaded and not partially overwritten.

Import Went Wrong

  • Use undo immediately if available.
  • Restore the snapshot created before import.
  • Retry import after reviewing `Review` and validation warnings.

Latest Changes Are Missing

  • Check whether the updated vault was actually downloaded.
  • Use save history and backups to identify the most recent file.
  • Remember that session edits are not permanent until exported.

Recovery Steps

  • Read the backup and recovery guide
  • Review the FAQ
  • Open the app and inspect snapshots or save history
