Import Guide

ZeroVault imports through a preview screen first. Review duplicate matches, validation warnings, and the chosen action before confirming.

Supported Sources

  • CSV exports from common password managers and browsers.
  • Bitwarden JSON where supported by the importer.
  • ZeroVault normalizes data into its own entry schema before merging.

Preview Actions

  • Import: add as a new entry.
  • Duplicate: force a new copy even if it matches.
  • Merge: combine compatible fields into an existing record.
  • Replace: overwrite an existing matching record.
  • Skip: leave the row out.
  • Review: resolve uncertain duplicate matches manually.

Duplicate Matching

  • Matches are scored from title, username, URL host, password, and category overlap.
  • Higher confidence rows default toward merge.
  • Lower confidence rows are intentionally conservative and may stay in review state.

Validation Warnings

  • Card expiry format, CVV length, bank account structure, and identity document issues are flagged.
  • Warnings should be reviewed before import, especially for non-login categories.

Safe Workflow

  1. Create a snapshot first.
  2. Import through preview.
  3. Review audit results after import.
  4. Download the updated vault and a timestamped backup.
