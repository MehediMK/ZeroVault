Offline Password Manager with Local Encryption

ZeroVault is an offline password manager built for users who want a client-side password vault without cloud lock-in. It runs in the browser, encrypts locally, and stores credentials in a portable encrypted JSON file you control.

If you are looking for a password manager without cloud sync, a local password vault, or an encrypted JSON password manager that works on static hosting, ZeroVault is designed for that workflow.

Why Users Choose ZeroVault

  • They want a password manager without mandatory cloud storage.
  • They want to keep their encrypted vault file themselves.
  • They need backup, restore, and recovery workflows that are explicit.
  • They want offline-first access on static hosting or local devices.

Password Vault Features

Password generation, password health audit, entry categories, sensitive mode, TOTP support, search, filters, favorites, archive, pagination, and bulk actions.

Backup and Recovery Features

Undo history, entry history, password history, named snapshots, restore points, download history, printable recovery sheets, and backup-oriented save flows.

Import and Migration Features

Import preview, duplicate matching, merge and replace options, validation warnings, and KDF metadata that supports future crypto migration paths.

How ZeroVault Works

  1. Create a new vault or open an encrypted JSON vault file.
  2. Manage passwords, TOTP secrets, identities, bank records, cards, and notes locally in the browser.
  3. Download the re-encrypted vault file after changes so your latest state is preserved.
