ZeroVault – Client-Side Offline Password Manager

Offline Client-Side Password Manager

ZeroVault is a secure password manager that runs entirely in your browser. All passwords are encrypted locally using modern cryptography and stored only in a downloadable JSON file that you control.

  • No cloud storage
  • No servers
  • No tracking
  • Works offline
Offline-capable. No servers. No storage. Download your encrypted vault JSON after changes.
