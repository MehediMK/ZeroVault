Security Model

ZeroVault is an offline-first local vault. The browser encrypts and decrypts the vault data, and you manage the encrypted JSON file yourself.

Core Security Rules

  • No cloud account or backend storage.
  • No automatic browser persistence of the live vault.
  • Every meaningful change should end with a new encrypted download.

Encryption and KDF

  • The vault is encrypted client-side before download.
  • `PBKDF2` is broadly compatible and always available.
  • `Argon2id` becomes available when a compatible runtime is loaded.
  • KDF choice is stored in vault metadata for future opens and migrations.

Sensitive Mode

  • Sensitive entries hide fields by default.
  • Reveal is per-field and automatically times out.
  • Hidden sensitive content is cleared when the tab is hidden.
  • Copying sensitive values can be disabled in security settings.

Clipboard and Auto-Lock

  • Clipboard content is auto-cleared on a timer when possible.
  • Auto-lock triggers after inactivity.
  • You can also lock immediately on tab hide.

What ZeroVault Does Not Protect Against

  • A compromised device or malicious browser environment.
  • Loss of your vault file if you keep no backups.
  • A weak master password.
