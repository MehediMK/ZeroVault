Frequently Asked Questions

These are the questions users usually ask first when they are used to browser-synced or cloud-based password managers.

Why do I need to download after changes?

ZeroVault keeps the live vault in memory while the app is open. Downloading creates the encrypted file you keep as the durable copy.

Does ZeroVault upload my data anywhere?

No. The design is local-first and offline-first. You control the encrypted JSON file.

What happens if I forget the master password?

The vault cannot be recovered by the app. There is no server-side recovery process.

Can I keep multiple backup versions?

Yes. You should keep timestamped copies and older known-good vault files until the newest file is verified.

What is the difference between snapshots and backups?

Snapshots are restore points stored inside the vault metadata. Backups are separate encrypted files you keep outside the running session.

Can I use Argon2id today?

Yes, if a compatible Argon2 runtime is loaded in the browser environment. Otherwise PBKDF2 remains available.

Is the app usable offline?

Yes. The app is static and includes PWA basics and service-worker caching for offline-capable usage.

How should I handle imports safely?

Create a snapshot first, use the preview screen, resolve uncertain matches, then review the audit report and download the updated vault.
