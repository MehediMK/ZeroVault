What Is a Client-Side Password Manager?

A client-side password manager performs encryption and decryption on the user’s device rather than on a remote server. ZeroVault follows this model in the browser and stores the result as an encrypted JSON vault file.

Core Idea

  • Browser handles crypto locally
  • Vault opens in memory only
  • User keeps the encrypted file

Why It Matters

Client-side password managers are attractive to users who want clearer trust boundaries. If the product is static and local-first, there is less infrastructure involved in handling secrets.

How ZeroVault Uses This Model

  • Local encryption and decryption
  • Portable encrypted JSON file output
  • No backend session required
  • Optional KDF migration support

User Responsibilities

  • Choose a strong master password
  • Keep backups
  • Download after changes
  • Protect the local device and browser environment
