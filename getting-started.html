Getting Started

ZeroVault works differently from cloud password managers: everything happens locally in your browser, and your vault file stays under your control.

Open App Read Backup Guide

Quick Path

  1. Create a new vault or open an existing encrypted JSON file.
  2. Add entries, tags, TOTP data, and recovery references.
  3. Review audit warnings and validation issues.
  4. Use Save & Download after changes.
  5. Keep older vault files until the new one is verified.

1. Create Your Vault

  • Choose a strong master password.
  • Select `PBKDF2` by default, or `Argon2id` if a compatible runtime is loaded.
  • Pick an auto-lock timeout that matches your risk tolerance.

2. Add Entries

  • Use categories like login, card, identity, bank, note, and license.
  • Enable sensitive mode for records that should stay hidden by default.
  • Use the built-in generator for new passwords and track rotation days.

3. Watch for Health Issues

  • Audit flags reused, weak, or expiring passwords.
  • Validation catches malformed card, bank, identity, and license fields.
  • Review the audit report before downloading major changes.

4. Save Correctly

  • Changes are not persisted until you download the updated vault file.
  • Create named snapshots before risky edits.
  • Use timestamped backup downloads for version safety.
