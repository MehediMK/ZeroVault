Backup and Recovery

Your encrypted vault file is the source of truth. If you lose it and have no backup, the data is gone.

Recommended Routine

  1. Create a named snapshot before major edits.
  2. Download the updated vault.
  3. Also download a timestamped backup.
  4. Keep previous copies until the new file opens successfully.

Snapshots

  • Snapshots are in-vault restore points.
  • Use them before imports, bulk edits, and password rotations.
  • Restoring a snapshot changes the live vault state, so download after restore.

Download History

  • The app records recent download actions inside the vault metadata.
  • Use it to verify when the last clean encrypted export was made.
  • Download history is not a replacement for external backups.

Recovery Sheet

  • Use the printable recovery sheet for recovery codes and file references.
  • Store printed material separately and securely.
  • Do not leave printed recovery data in shared spaces.

Failure Scenarios

  • If a new file fails to open, retry with the previous downloaded copy.
  • If you forget the master password, ZeroVault cannot recover the vault.
  • If import or bulk edit goes wrong, use undo or restore a snapshot immediately.
